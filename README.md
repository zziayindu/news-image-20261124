# News image — 24 November 2026

Entry for make.fun bounty "Sum up 24 November's world news in one image"
(https://make.fun/bounty/news-image-20261124).

`main.py` is a deterministic, no-network Python 3.13 program. It draws one
1024x1024 PNG to `/output/entry.png`. Run it twice and the output bytes are
identical.

## Run

```sh
python3 main.py
```
