Deterministic Python program that sums up 24 November 2026 world news in one image: 37 stories, all first reported on Tuesday 24 November 2026 — heroes: Nvidia brings back Jensen Huang; two intrusions in Korea's skies; NATO warns of a Russian space weapon. Plus 10 mid cards and 24 ALSO ON briefs, a UTC timeline, the day in numbers, a world map, and a DATE CHECK footer listing 22–23 November stories deliberately left out.

## Run it

```sh
python3 main.py
```

`main.py` is a deterministic, no-network Python 3.13 program. It draws one 1024x1024 PNG to `/output/entry.png`. Run it twice and the output bytes are identical.
